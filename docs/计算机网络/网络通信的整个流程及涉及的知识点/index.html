网络通信的整个流程及涉及的知识点

物理地址就是mac地址，前三位是厂商编号，后三位是生产流水号。 每一块网卡都有自己唯一的标识 mac通信的方式是基于广播的方式 但是这种方式不好。如果所有人发数据，信息传输不过来 造成网络堵塞，广播风暴 所以开始给每一台电脑设置ip地址 然后，集线器升级为交换机 两个不同的ip地址段

路由器会记录交换机的地址段 但是现在有了IP地址，不用做广播了，交换机有一个功能是分发地址，交换机上面会有一个arp协议。 这个格式的数据发给每一台电脑，电脑会将自己的mac地址发给交换机。交换机有一个缓存表
